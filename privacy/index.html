隐私政策

最后更新：2026-11-25

这份政策说明小兴365 工具站（xiaoxing365.top，以下简称“本站”）会处理哪些数据、为什么处理，以及你可以怎么选择。本站不设置用户账户，也不要求你填写姓名、手机号等个人信息。

1. 工具输入的数据

本站绝大多数工具在浏览器本地运行：你输入的文本、JSON、JWT、密码、图片等内容只在当前页面内计算和显示，不会发送到本站服务器，也不会被保存。刷新或关闭页面后，这些内容通常就不再保留。

例外：域名比价工具（/domain-price/）会把你查询的域名后缀发送到哪煮米（nazhumi.com）的公开 API，以获取各注册商的价格数据。该请求受哪煮米自己的隐私政策约束。

2. Cookie 和广告

本站使用 Google AdSense 展示广告。Google 及其合作伙伴可能会使用 Cookie 或类似技术，根据你访问本站和其他网站的记录展示广告，并衡量广告效果。你可以访问 Google 广告设置 管理个性化广告，或通过浏览器设置清除、限制 Cookie。

如果你所在地区要求广告同意，Google 可能会显示同意提示；你也可以使用浏览器扩展或隐私设置限制跟踪。

3. 统计分析

本站通过 Google Tag Manager 加载统计代码，可能记录页面浏览、设备类型、浏览器、来源页面等汇总信息，用于了解哪些工具更常用、页面是否正常。统计代码可能设置 Cookie；具体处理方式受 Google 的隐私政策约束。

4. 访问日志

本站托管在 GitHub Pages。GitHub 可能为了安全和运营记录访问日志，例如 IP 地址、User-Agent、请求时间和访问的页面。本站不自行建立访问日志数据库。

5. 外部链接

本站会链接到博客、域名注册商官网、Google 等第三方网站。离开本站后，你的数据将按对方网站的隐私政策处理，本站无法控制。

6. 你的选择

你可以随时清除浏览器 Cookie、使用隐私模式，或通过浏览器设置阻止第三方 Cookie。这样做可能影响广告展示，但不会影响大多数工具的核心功能。

7. 政策更新

如果本站新增第三方服务或改变数据处理方式，会更新这份政策并修改页面顶部的日期。建议在涉及敏感数据时先查看最新版本。

8. 联系

对隐私政策有疑问，或希望了解某类数据的处理方式，请发邮件到 mcxiaoxing365@163.com。
