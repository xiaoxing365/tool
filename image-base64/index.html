关于 图片转 Base64

把图标或小图转成 Base64 Data URL，可以直接写进 HTML、CSS 或 Markdown，减少一次图片请求。这个工具在浏览器本地读取图片，不会上传服务器。

怎么用

  1. 选择一张不超过 2MB 的图片。
  2. 查看图片信息和生成的 Data URL。
  3. 点「复制」把 Data URL 用到 HTML、CSS 或 Markdown 里。

常见问题

图片会被上传吗？

不会。文件只在浏览器里读取和转换，页面没有上传接口。

为什么大图不适合转 Base64？

Base64 会让体积增加约 1/3，还会撑大 HTML/CSS 文件，建议只用于图标和小图。
