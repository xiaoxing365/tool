关于 HTML 实体编码解码

  
在 HTML 里直接写 <、>、& 等字符可能破坏结构，评论或用户输入也需要转义。这个工具支持命名实体和数字实体的转义、反转义，反转义只按实体表解码，不会执行 HTML。

  
怎么用

  
    
    
  1. 把要处理的文本粘到输入框。
    2. 
    
  2. 点「转义」把特殊字符变成实体，或点「反转义」把实体还原成字符。
    3. 
    
  3. 复制结果；反转义不会解析标签，粘进来的 HTML 只会作为文本显示。
    4. 
  

  
常见问题

  
转义和反转义有什么区别？

  
转义把 & 变成 &amp;、< 变成 &lt;；反转义做相反操作，把实体还原成原始字符。

  
反转义会执行 HTML 吗？

  
不会。工具只做字符串替换，不把结果插入页面，也不会执行脚本。
