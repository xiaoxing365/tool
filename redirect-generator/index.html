关于 Cloudflare 重定向表达式生成器

换域名或做 301 跳转时，Cloudflare 的 Redirect Rules 需要一段表达式。这个工具把旧域名、新域名、路径和查询参数拼成匹配表达式与目标 URL，复制后就能粘到 Cloudflare 规则里。

怎么用

  1. 填旧域名和新域名，域名不要带 https:// 或结尾斜杠。
  2. 按需勾选「保留路径和参数」和「同时匹配 www 子域名」。
  3. 复制匹配表达式和目标 URL，在 Cloudflare 的「规则 → 重定向规则」中创建规则，状态码选 301。

常见问题

生成的表达式能直接粘贴到 Cloudflare 吗？

可以，格式对应 Cloudflare Rules 的表达式语法；保存前建议在规则编辑器里确认字段和预览结果。

旧域名需要先接入 Cloudflare 吗？

需要。只有 DNS 托管在 Cloudflare 且开启代理的域名，重定向规则才会生效。
