文本编码转换器

UTF-8 和 GBK 互转，中文乱码的时候用得上。

常见的两种乱码：浣犲ソ 是 UTF-8 字节被按 GBK 解读，用第 2 个方向还原； ÄãºÃ 是 GBK 字节被按 Latin-1 显示，用第 4 个方向还原。
GBK 解码由浏览器内置编码支持完成，建议使用较新的 Edge / Chrome。

关于 文本编码转换器

中文乱码通常不是内容坏了，而是编码被按错误的字符集解读。这个工具支持 UTF-8 与 GBK 互转，以及两种常见的乱码还原方向。

怎么用

  1. 选择转换方向：UTF-8 → 乱码、乱码 → UTF-8、UTF-8 → 字节乱码、字节乱码 → UTF-8。
  2. 把文本粘到输入框，点「转换」。
  3. 复制结果；如果还是乱码，换另一个方向再试。

常见问题

「浣犲ソ」怎么还原成「你好」？

这是 UTF-8 字节被按 GBK 解读，选择「乱码 → 正常 UTF-8」方向即可。

「ÄãºÃ」是什么乱码？

这是 GBK 字节被按 Latin-1 显示，选择「字节乱码 → 正常 UTF-8」方向还原。
