关于 JWT 解码器

JWT 由 Header、Payload 和签名三部分组成，调试登录态时经常需要看里面到底写了什么。这个工具只做 Base64URL 解码展示，不验证签名。

怎么用

  1. 把 JWT Token 粘到输入框。
  2. 点「解码」查看 Header、Payload 和签名段长度。
  3. 复制需要的内容；不要把生产环境的 Token 发给不可信的工具。

常见问题

解码 JWT 会验证签名吗？

不会。工具只解码内容，不能证明 Token 未被篡改，签名验证要在服务端做。

Payload 里的 exp 是什么？

exp 是过期时间，通常是 Unix 时间戳；可以用本站的时间戳工具转换查看。
