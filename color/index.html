关于 颜色转换器

设计稿、CSS 和品牌规范里经常需要在 HEX、RGB、HSL 之间转换。这个工具支持三种格式互转，并实时预览颜色。

怎么用

  1. 用取色器选颜色，或直接填写 HEX、RGB、HSL 数值。
  2. 查看其他格式的转换结果和颜色预览。
  3. 复制需要的 CSS 片段。

常见问题

HEX 支持 3 位简写吗？

支持，例如 #fff 会按 #ffffff 处理。

HSL 和 RGB 能完全互转吗？

可以，二者只是同一颜色的不同表示方式，转换不会改变颜色。
