关于本站

一个纯前端的小工具站，做站和调试时顺手用。

这个站是什么

小兴365 工具站收集了一些建站、编码转换、文本处理和开发调试时常用的小工具。所有工具都打开即用，不需要注册或登录，手机上也能操作。

为什么做这个站

平时做网站、改配置、处理文本时，经常会遇到一些一次性小需求：生成一段 Cloudflare 重定向表达式、转一下 Base64、查一个域名后缀的续费价。为这些需求单独装软件不划算，所以把常用的小工具放在一个站点里，自己用着方便，也分享给需要的人。

数据怎么处理

绝大多数工具是纯前端实现，输入内容只在你的浏览器里计算，不会上传到服务器。例外是域名比价工具，它会把你查询的域名后缀发送到哪煮米（nazhumi.com）的公开 API 获取价格；具体说明见隐私政策。

技术栈

站点托管在 GitHub Pages，使用静态 HTML、CSS 和原生 JavaScript。首页和工具页在构建时生成静态内容，方便搜索引擎抓取；工具逻辑不依赖后端服务。
