关于 URL 编码解码

  
URL 里的中文、空格和特殊字符需要编码后才能安全传输。这个工具支持 encodeURIComponent 风格的编码和解码，适合处理查询参数、回调地址和接口调试。

  
怎么用

  
    
    
  1. 把要处理的文本或 URL 参数粘到输入框。
    2. 
    
  2. 点「编码」把特殊字符转成 %XX，或点「解码」还原。
    3. 
    
  3. 复制结果；整条 URL 建议只编码参数值，避免把 :// 也编掉。
    4. 
  

  
常见问题

  
空格会变成什么？

  
编码后通常变成 %20；在表单提交里也可能看到 +，两者含义略有不同。

  
为什么不能直接编码整条 URL？

  
会把协议、域名和路径分隔符一起编码，导致链接失效；只编码参数值更安全。
