关于 CSS 格式化压缩

压缩后的 CSS 很难读，格式化后的 CSS 又占空间。这个工具可以在美化缩进和压成一行之间切换，适合整理样式表或排查压缩问题。

怎么用

  1. 把 CSS 粘到输入框。
  2. 点「格式化」按缩进展开，或点「压缩」去掉多余空白。
  3. 点「复制」把结果带走；格式化不会改变选择器和属性值。

常见问题

压缩会删除注释吗？

会去掉多余空白和注释，减小体积；需要保留注释时请先备份原文件。

支持 SCSS 或 Less 吗？

工具面向标准 CSS，SCSS/Less 的变量和嵌套语法可能无法正确格式化。
