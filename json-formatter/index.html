关于 JSON 格式化

接口返回的 JSON 经常是一整行，直接看很费劲。这个工具可以把 JSON 格式化缩进、压缩成一行，并在解析失败时给出错误提示。

怎么用

  1. 把 JSON 粘到输入框，选择 2 空格或 4 空格缩进。
  2. 点「格式化」查看结构，或点「压缩成一行」得到紧凑结果。
  3. 点「复制」把结果带走；解析失败时先检查逗号、引号和括号。

常见问题

格式化会改变 JSON 的内容吗？

不会，只调整空白和缩进；键值、顺序和数据类型都保持不变。

支持多大的 JSON？

常规接口数据没问题；特别大的文件可能受浏览器内存限制，建议分块处理。
